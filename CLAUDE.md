# Wind Loader — project notes for Claude

## What this is
A web tool for façade wind loads on the vertical walls of rectangular buildings to
BS EN 1991-1-4:2005+A1:2010 with the UK National Annex, PD 6688-1-4 and the CWCT Standard for
systemised building envelopes Part 2, plus a marketing site. The report output follows the layout of a
consultant's façade wind load report. Client project names and data must never appear in
the app, the site or the docs; the validation reports are referred to only as Report A and B.

## Layout (pnpm workspace, Node 22)
- `packages/engine` — pure TypeScript calculation engine. No UI, no I/O.
  - `src/data/*.ts` — every number taken from a reference document, each with its source
    (document, clause/table, page). `charts.ts` is generated by `tools/digitise`.
  - `src/wind.ts` — qp per direction, zones, funnelling, net and design pressures.
  - `src/index.ts` exports `runWind()` and `zoneLoads()` (used by the glass, stone and GRC tools).
- `apps/app` — Vite + React checker (inputs left, building view centre, results right, Word report).
- `apps/site` — static multi-page landing site (Netlify Forms contact form).
- `validation/` — hand-computed reference cases compared with the engine to 1 in 10^5.
- `tools/digitise` — rebuilds Figures NA.7 and NA.8 from the NA PDF's vector paths.
- `docs/calc-spec.md` — the release-1 calculation spec. The engine implements this and nothing
  else. Change the spec first.
- `docs/open-questions.md` — every value or rule the documents leave open (OQ-xx).
- `docs/reference/` — the standards. Licensed copies are git-ignored; only the README is committed.

## Rules
- Never invent engineering values. If the documents do not give it, use `TODO_VALUE` and add an
  entry to `docs/open-questions.md`. Template values are labelled as examples.
- Where documents disagree or leave a choice to the engineer, make it a user parameter with the
  default the standard states, and raise an advisory when the user departs from it.
- Units inside the engine: m, km, m/s, kN/m² (kPa), degrees clockwise from north.
- `pnpm test` and `pnpm typecheck` must be green before each commit.
- Do not copy other websites. Keep the non-affiliation disclaimer for BSI, CEN and CWCT. Results
  must be checked by a qualified engineer.

## Commands
- `pnpm install`
- `pnpm test` — all workspace tests
- `pnpm typecheck` — tsc across the workspace
- `pnpm --filter @wind/validation validate` — print the validation table
